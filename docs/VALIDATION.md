# Template Validation Checklist

Use this checklist to ensure each template or example is complete, clear, and AI-ready before release.

## General
- [ ] All required sections are present
- [ ] All placeholders are filled or documented
- [ ] Markdown renders correctly on GitHub
- [ ] No TODOs or unresolved comments remain
- [ ] File naming and location match conventions

## Clarity
- [ ] Each section is concise and unambiguous
- [ ] Domain/business rules are explicit
- [ ] API contracts are testable and versioned
- [ ] Refactor rules and coding standards are actionable

## AI-Readiness
- [ ] Instructions are explicit for AI agents (see AGENTS.md)
- [ ] Placeholder usage is consistent with [PLACEHOLDERS.md](PLACEHOLDERS.md)
- [ ] Context loading and navigation tips are present

## Example-Specific
- [ ] Stack and architecture are clearly described
- [ ] Example-specific overrides are documented
- [ ] All sample data and diagrams are included if referenced

---

Attach this checklist to PRs or releases for new/updated templates and examples.
