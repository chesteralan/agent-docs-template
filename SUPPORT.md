# Support

If you need help using these templates, use one of the options below.

## How To Get Help

- Open a GitHub issue for bugs or feature requests
- Start a discussion for usage questions and ideas
- Review README and example projects before opening support requests

## What To Include In A Support Request

- What you were trying to do
- Which template or example you used
- Expected outcome and actual outcome
- Relevant snippets or screenshots

## Response Expectations

- Best-effort community support
- No guaranteed SLA
- Critical security concerns should be reported via SECURITY.md
