# Example: Firebase App

This folder contains a fully filled-out set of documentation templates for a realistic SaaS project stack, including:

- Firebase Authentication
- Cloud Firestore
- Cloud Functions
- Firebase Hosting
- TypeScript, Firebase SDK, Cloud Functions, Firebase Emulator Suite, Playwright

## Purpose

Demonstrates how to use and customize all core documentation templates in a modern full-stack project. Use these docs as a reference or starting point for your own projects.

## Included Example Docs

- AGENTS.md — AI agent instructions and coding rules
- ARCHITECTURE.md — System design and technical architecture
- API_CONTRACTS.md — API expectations and patterns
- BUSINESS_RULES.md — Domain/business logic
- CODEBASE_MAP.md — Project structure
- GLOSSARY.md — Shared terminology
- REFACTOR_RULES.md — Safe refactoring guidelines
- UI_PATTERNS.md — UI/UX and component standards

## How to Use

1. Review each doc for structure and content ideas
2. Copy and adapt templates for your own stack
3. Keep docs updated as your project evolves
4. Validate your documentation using the [VALIDATION.md](../../docs/VALIDATION.md) checklist before release or PR.
