# GLOSSARY

Shared definitions for domain and engineering terminology.

## Domain Terms

- Project: A collection of tasks and users
- Task: Work item assigned to a user
- Team: Group of users collaborating on projects

## Product Terms

- Seat: A paid user slot in a team
- Workspace: Top-level container for teams and projects

## Technical Terms

- SPA: Single Page Application
- SSR: Server Side Rendering
- SSO: Single Sign-On
- CRUD: Create, Read, Update, Delete

## Ambiguous Terms

- Owner: In this repo, means team admin (not code owner)
- Archive: Means soft-delete, not permanent removal

## Naming Conventions

- Prefix and suffix meanings: use 'Dialog' for modals, 'List' for collections
- Reserved words: 'admin', 'system', 'root'
- Abbreviations allowed: SSO, CRUD, API, DB
