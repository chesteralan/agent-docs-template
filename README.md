# agent-docs-template

A reusable documentation template that helps AI agents quickly understand your codebase, architecture, business rules, and engineering standards.

## Purpose

Modern AI coding agents perform best when projects provide clear, structured, and consistent context.

This repository provides a standardized documentation system designed to improve:

- AI-assisted development
- Codebase onboarding
- Architectural understanding
- Refactoring safety
- Engineering consistency
- Knowledge sharing

The goal is to make repositories easier for both humans and AI agents to navigate and understand.

---

# Included Documents

## Core Context Documents

| File | Purpose |
|------|---------|
| `README.md` | Project overview and setup |
| `AGENTS.md` | AI agent instructions and coding rules |
| `ARCHITECTURE.md` | System design and technical architecture |
| `CODEBASE_MAP.md` | High-level project structure |
| `BUSINESS_RULES.md` | Important domain/business logic |
| `API_CONTRACTS.md` | API expectations and patterns |
| `UI_PATTERNS.md` | UI/UX and component standards |
| `REFACTOR_RULES.md` | Safe refactoring guidelines |
| `GLOSSARY.md` | Shared terminology |

---

# Why This Exists

AI agents often struggle because repositories lack:

- architectural clarity
- consistent patterns
- business context
- engineering standards
- discoverable documentation

This template helps solve that problem by creating a centralized source of project context.

# Best Practices

## Keep Documentation Close to the Code

Update docs whenever:
- architecture changes
- business logic changes
- conventions evolve
- new patterns are introduced

---

## Prefer Explicit Rules

AI agents perform better with:
- clear conventions
- consistent folder structures
- documented decisions
- reusable patterns

---

## Document Intent, Not Just Implementation

Good documentation explains:
- what
- why
- constraints
- tradeoffs

—not just code behavior.
