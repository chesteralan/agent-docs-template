# Enterprise Template

A comprehensive template for multi-team systems with stricter governance and review practices.

## Included Files

- AGENTS.md
- ARCHITECTURE.md
- API_CONTRACTS.md
- BUSINESS_RULES.md
- CODEBASE_MAP.md
- GLOSSARY.md
- REFACTOR_RULES.md
- UI_PATTERNS.md

## Best For

- Large organizations
- Multi-team platforms
- Systems with compliance and audit needs

## How To Use

1. Copy this folder into your project docs directory
2. Fill placeholders with explicit operational details
3. Enforce updates in pull request review workflows
