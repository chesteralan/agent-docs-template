# Minimal Template

A lightweight documentation template for small projects, prototypes, or early-stage codebases.

## Included Files

- AGENTS.md
- ARCHITECTURE.md
- CODEBASE_MAP.md
- BUSINESS_RULES.md

## Best For

- Solo projects
- MVPs and prototypes
- Teams that need minimal process overhead

## How To Use

1. Copy this folder into your project docs directory
2. Replace placeholders with project-specific values
3. Expand to full templates as complexity grows
4. Validate your documentation using the [VALIDATION.md](../../docs/VALIDATION.md) checklist before release or PR.
